# Typewolf: workflow guide

What this reference covers: Typewolf as a Fontlore workflow tool: what it is, where it sits in the research stage, how to use it well, and what evidence to record from it.

## What it is

Site-of-the-month archives, pairings, and trending data; one signal among many.

- Section: evidence
- Access: freemium
- URL: https://www.typewolf.com/

## Where it sits in the Fontlore workflow

This tool belongs to the **research** stage. Concretely: find real-world usage in the same industry and medium; treat popularity as a weak prior. It feeds records into the decision log, not opinions into the chat.

## How to use it well

- Go in with the project constraints written down: scripts, sizes, license scope, medium.
- Record what the tool returned, not what you hoped it would return.
- Prefer the tool's own primary data (files, license text, metadata) over summaries elsewhere.
- Combine with at least one independent source before treating a fact as verified.

## Evidence to record

When this tool contributes to a decision, log: example URL, industry, medium, and what the example demonstrates.

## Limitations and cautions

Usage examples prove popularity, not quality. Two projects in different industries may need opposite choices.

## Common mistakes

- Copying tool output into the decision log without the URL and date.
- Letting one tool be the single source of truth for license facts.
- Using the tool outside its stage: identification tools do not verify licenses, catalogs do not test rendering.
