# Guides index

What this reference covers: the 632 generated compendium guides in Fontlore - one page per font, per pairing, and per tool, built from the data layer by scripts/generate_guides.py at release time. Each guide is short, factual, and cross-linked to the curated references.

## Fonts (495)

Per-font guides: classification, scripts, weights, sources, cautions

## Pairings (66)

Per-pairing guides: why the combination works and where to use it

## Tools (71)

Per-tool guides: what it is, where it sits in the workflow, evidence to record

Browse by file name; slugs match the data layer exactly.
