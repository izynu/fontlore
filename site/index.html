Data integrity

Verified, or null

Source URLs on every record

Each font points at its own foundry page or repository. Verified at the source, not at aggregators.

Null, never guessed

Unverifiable values stay null. The schema makes missing data visible instead of plausible.

CI-gated on every commit

validate.py checks JSON schemas, pairing integrity, house style, and every cross-link before merge.

Licenses as SPDX ids

OFL-1.1, Apache-2.0, UFL-1.0, ITF-FFL-1.0, MIT. Anything else must be read in full, in the guide.

Quick start

Run the decision engine

git clone https://github.com/izynu/fontlore.git
cd fontlore
python3 scripts/decide.py --project dashboard --script latin --tone neutral
python3 scripts/decide.py --project marketing --script devanagari --tone editorial --json

Hard-filters by script and license, scores against the rubric, prints ranked reasons, and suggests curated pairings.

Build the site yourself

This entire site is generated from the data layer by a single stdlib-only script. After any data change:

python3 scripts/build_site.py

727 pages, no dependencies, no tracking. Deployed to GitHub Pages by the included workflow.
